# Profile artwork

## Final selected typography prompt

```text
Use case: precise-object-edit
Edit target: Ahmed Sakri's existing GitHub profile banner.
The user dislikes both the original heavy block capitals and the later formal high-contrast serif. Replace ONLY the name lettering with a beautifully set contemporary rounded humanist sans-serif, close to Satoshi Medium or Avenir Next Medium, with softly rounded forms and a single-storey lowercase 'a'. Exact name: 'Ahmed Sakri', title case, ONE LINE. Medium-light weight, clean uniform strokes, graceful open counters, comfortable natural kerning. No serifs, no calligraphy, no bold block letters, no wide artificial letterspacing. It should look like a premium modern product designer/developer identity. Warm ivory lettering, large but approximately 10 percent smaller than the current serif name. Keep it optically centered in the left text region with generous breathing space.
Preserve the 3:1 banner framing, all right-side artwork, lighting, palette, supporting WEB DEVELOPER line and Mumbai, India / AppsOverFlow line. Do not change any other words or objects. Deliver the complete revised banner.
```

The README uses repository-hosted assets so its design does not depend on live statistics-card services.

- `ahmed-sakri-banner.png`: custom profile banner generated with the built-in image-generation tool, then revised to use rounded modern lettering, Ahmed's selected direction.
- `fireboy-watergirl.png`: the AppsOverFlow game's existing public social artwork, reused unchanged.
- `badges/*.svg`: static technology and navigation badges from Shields.io, saved locally. Technology logos identify tools used; they do not represent certifications or endorsements.
